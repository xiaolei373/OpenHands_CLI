# 变更记录（Change Records）

本目录为每一次**非平凡代码改动**保存一份记录，便于回溯"为什么改、影响什么、怎么验证、是否动了 spec"。

## 约定

- 一次逻辑改动 = 一个文件：`docs/changes/YYYY-MM-DD-<简短英文slug>.md`。
- 从 [`_TEMPLATE.md`](./_TEMPLATE.md) 复制后填写。
- 只对**非平凡改动**建记录：改逻辑、依赖、`openhands-cli.spec`、对外接口/行为、`vendor/` 下的 SDK。纯格式化、typo、注释可跳过。
- 记录随对应改动**同一个提交/评审**一起提交，保证代码与记录不脱节。

## 为什么不只靠 git log

git 记录了"改了哪些行"，但这里补充了 git 里没有的：改动**背景/动机**、**影响范围判断**、**实际验证过程与结果**、以及**是否需要同步改 spec**。四者齐全才能在几个月后安全地回溯或回滚。

完整工作流见仓库根 `AGENTS.md` 的 “Change Workflow (MUST)” 一节。
